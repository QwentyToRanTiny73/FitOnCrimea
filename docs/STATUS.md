## Что сделано

  lint, проверка типов, сборка, проверка результата `scripts/verify-export.mjs`.

- Удалены выдуманные факты (сроки годности, «без парабенов» и др.). Контакты взяты из брошюры.

**Данные**

  «Гладкие пятки», «Здоровые суставы», «Белоснежка», «Омолаживающий» (бывший «Лимонник и роза»),

### В ветке, ждёт мерджа

**Интерактивная схема точек массажа (`/massage-points`)**
- Номера на схеме — кнопки. Выбранная точка подсвечивается, места на теле мигают.
  Координаты сверены наложением на картинку.
- Описание точки: показания (из брошюры), где на схеме, совет по зоне тела, общая методика
  из 6 шагов, бальзамы с теми же показаниями (совпадение слов, 15 из 26 точек).
- На телефоне описание открывается шторкой снизу, на ПК — закреплённой панелью рядом со схемой.
- Фильтры по симптомам, поиск, кнопки «Предыдущая» и «Следующая», ссылка на точку
  (`/massage-points/#t5`), закрытие по Esc.
- Для острых состояний (точки 1, 11, 14, 18) — предупреждение «сначала врач, 103 или 112»;
  для гипертонии, гипотонии и атеросклероза (2, 10, 26) — «только дополнение к лечению».
- Данные: `src/data/massage-points.ts`, компонент: `src/components/massage/MassageExplorer.tsx`.

**Главная**
- Из блока цифр убраны «лет бренду» и «сортов мыла». Остались «бальзамов в каталоге» и «точек массажа».

**Проверки**
- `npm run check` проходит.
- Браузерные тесты: схема точек — 27/27 на телефоне и ПК. Прежний набор — 49/49.

## Принятые решения

| Решение | Почему |
|---|---|
| GitHub Pages, статический экспорт | Бесплатно, без сервера. Покупки идут через Ozon |
| Покупка только на Ozon, корзины нет | Бизнес-правило владельца |
| Вход администратора ключом GitHub, а не паролем | Права проверяет GitHub. Хэш пароля в коде страницы подбирается. Ключ всё равно нужен для публикации |
| Публикация = коммит `overrides.json` и фото | Без сервера и CMS. Вся история и откат — в Git |
| Черновики админки хранятся в браузере | На статическом сайте нет бэкенда |
| `sanitize.ts` для всех правок | Ошибка в данных не должна ломать сборку и сайт |
| Стиль по брошюре: засечки, пергамент, акварель | Запрос владельца. Отличие от конкурентов: у всех шрифты без засечек и фото на белом |
| Тексты только из брошюры и данных владельца, черновики помечены | Правило «не выдумывать факты» |
| Без имён владельцев и сотрудников, контакты из брошюры | Бизнес-правило |
| Один workflow и проверка `out/` перед публикацией | Раньше были двойные деплои и «README вместо сайта» |
| Код разложен по `config/`, `data/`, `services/`, `providers/` | Правка в одном месте. Сервис подключается заменой реализации в `services/index.ts` |
| Презентация-шпаргалка не в репозитории | Личный материал владельца |
| В схеме точек бальзамы подбираются только по совпадению слов в показаниях | Иначе это была бы догадка: брошюра говорит о массаже «с Крымским бальзамом» без привязки к конкретному |
| Методика массажа помечена как общие правила | В брошюре для точек есть только показания |
