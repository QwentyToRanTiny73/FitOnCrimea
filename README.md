# Фитон Крым — сайт-витрина

Магазин натуральной крымской косметики. Каталог бальзамов с поиском и
фильтрами, схема точек массажа, избранное, личный кабинет и редактор
каталога для администратора. Покупка — на Ozon.

Демо: <https://qwentytorantiny73.github.io/FitOnCrimea/>

## Стек

Next.js 14 (App Router, статический экспорт) · TypeScript · Tailwind CSS ·
хостинг GitHub Pages. Сервера нет: сайт собирается в набор HTML-файлов.

## Команды

```bash
npm install
npm run dev        # разработка: http://localhost:3000
npm run check      # lint + типы + сборка + проверка out/ — запускать перед пушем
```

## Кабинет администратора (/admin)

Ссылки на кабинет на сайте нет — открывайте адрес `/admin` напрямую (сохраните в закладки).

**Вход — логин и пароль**, которые вы придумываете сами при первом входе на устройстве.
Вместе с ними один раз указывается ключ доступа GitHub (fine-grained token) — он даёт право
публиковать. Ключ хранится только в вашем браузере, зашифрованный паролем (PBKDF2 + AES-GCM);
в репозиторий и на сайт ни пароль, ни ключ не попадают. Как получить ключ (2 минуты):
GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token →
Repository access: *Only select repositories* → `FitOnCrimea` →
Permissions: **Contents: Read and write** → Generate.

- Без галочки «Оставаться в системе» кабинет закрывается после 30 минут бездействия.
- После 5 неверных паролей вход ставится на паузу (30 с, затем дольше).
- Второе устройство: «Учётная запись» → «Скачать файл входа», на новом устройстве — «Загрузить файл входа».
- Забыли пароль: «Настроить вход заново» и снова указать ключ GitHub.

**Разделы:**
- *Обзор* — сколько товаров на витрине, без фото, без ссылки Ozon, что не опубликовано.
- *Товары* — поиск и фильтры, правка карточки, фото JPEG/PNG (кнопка или перетаскивание), «Скрыть».
- *Новый товар* — название, раздел, цена; адрес страницы заполняется сам.
- *Оформление* — замена картинок сайта (обложка, марки, иконки разделов, линейки) и баннеры на главной.
  JPEG и PNG; PNG с прозрачным фоном сохраняет прозрачность. Картинка уменьшается и сжимается в браузере.
- *Публикация* — все черновики одним коммитом: товары → `src/data/catalog/overrides.json` и `public/products/`,
  оформление → `src/data/design/overrides.json` и `public/design/`. Сайт пересобирается за 2–3 минуты.
- *Таблица Excel* — скачать CSV, поправить цены/ссылки/тексты, загрузить обратно.
- *Учётная запись* — смена логина и пароля, замена ключа GitHub, файл входа для другого устройства.

До публикации правки — черновики в браузере администратора (их видит только он).
Вся история публикаций хранится в GitHub, любую версию можно вернуть.

## Картинки

| Что | Куда | Формат |
|---|---|---|
| Фото товара | через кабинет или `public/products/<slug>.webp` | JPEG или PNG, около 1000×1000 |
| Картинки оформления и баннеры | через кабинет → «Оформление» (попадают в `public/design/`) | JPEG или PNG; размер подсказан у каждого места |
| Иллюстрации брошюры | `public/brochure/` (описаны в `src/config/brochure.ts`) | WebP |
| Логотип | `public/logo.svg` | SVG |

В коде локальные картинки подключаются только через `assetUrl("/путь")` — иначе на GitHub Pages
они потеряют префикс `/FitOnCrimea` и не загрузятся.

## Оформление

Стиль повторяет брошюру «Целебные бальзамы Крыма»:
- цвета — `tailwind.config.ts` (`brand.crimson` заголовки, `brand.green` лента логотипа,
  `brand.amber` золотые поля, `brand.beige` пергамент и др.);
- шрифты — `src/app/layout.tsx` (Old Standard TT, Ruslan Display, Inter);
- текстуры бумаги, опалённые края, рамка-марка — `src/app/globals.css`
  (`.paper-page`, `.cover-paper`, `.stamp`, `.title-crimson`);
- эмблема, лента со слоганом, золотые травы, баночка-плейсхолдер — `src/components/ui/Brochure.tsx`.

## Как добавить товар в коде

- Новый бальзам — блок в `src/data/catalog/balms.ts` с уникальными `id` и `slug`.
- Поля: `tagline` (красная строка растений), `subtitle`, `description` (текст брошюры),
  `badges: ["hit"]`, `pairsWith`, `hidden`, `ozonUrl`, `images`.
- Мыло и бальзамы для губ — файлы `soap.ts` / `lip-balms.ts` по образцу, подключить в
  `data/catalog/index.ts`, в `config/categories.ts` поставить `available: true`.

## Подключаемые сервисы

Все внешние зависимости собраны в `src/services/index.ts`. Каждый сервис описан
интерфейсом, сейчас подключены демо-реализации на `localStorage`:

| Сервис | Сейчас | Чем заменить |
|---|---|---|
| `auth` — вход, регистрация | данные в браузере посетителя | Supabase Auth, Яндекс ID, Auth.js |
| `catalogStore` — черновики админки | браузер администратора | — |
| `designStore` — черновики оформления | браузер администратора | — |
| `publisher` — публикация | GitHub API (коммит в репозиторий) | любой CMS с API |
| `favoritesStore` — избранное | браузер (годится и для продакшена) | синхронизация с аккаунтом |

Замена = новая реализация того же интерфейса + одна строка в `services/index.ts`.
Страницы и компоненты при этом не меняются.

## Деплой (GitHub Pages)

Workflow `.github/workflows/nextjs.yml` срабатывает при пуше в `main`: проверяет код,
собирает сайт, проверяет результат (`scripts/verify-export.mjs`) и публикует `out/`.

Настройка репозитория (один раз): **Settings → Pages → Source: GitHub Actions.**
Если после обновления сайт на минуту-две показывает README, источник стоит «Deploy from a branch»:
в Actions у каждого пуша тогда два запуска — наш «Deploy to GitHub Pages» и чужой «pages build and
deployment». Сборка в этом случае выводит предупреждение «Неверный источник GitHub Pages».
Секреты для входа не нужны: логин и пароль администратор задаёт сам в `/admin`.
Если в Settings → Secrets остались `ADMIN_PASSWORD_HASH`, `ADMIN_EMAIL`, переменная `ADMIN_LOGIN` —
их можно удалить, сайт их больше не читает.

Свой домен: Settings → Pages → Custom domain → `phyton-crimea.ru`, у регистратора
CNAME на `qwentytorantiny73.github.io`. Префикс `/FitOnCrimea` уберётся автоматически.

## Перед публичным запуском

- Тексты 5 бальзамов сверены со страницами брошюры (пометки «Брошюра, с. N» в `balms.ts`):
  «Гладкие пятки», «Здоровые суставы», «Белоснежка», «Омолаживающий», «Антицеллюлитный».
  У остальных поля «Способ применения» и «Противопоказания» — черновики, их проверяет производитель.
- В брошюре серия названа «из двадцати пяти» бальзамов, на сайте 24. На с. 8 виден
  «Противогрибковый» — его данных нет (страница обрезана на фото).
- Права на акварели брошюры для сайта — уточнить у правообладателя.
- Политику конфиденциальности (`/privacy`) должен посмотреть юрист.
- Добавить фото товаров и ссылки на Ozon; ссылку на магазин — `site.marketplace.storeUrl`.
